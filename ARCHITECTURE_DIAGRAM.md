## 🚀 Как запустить

### Опция 1: Через Make
```bash
make dev          # Запустить в режиме разработки

```

### Опция 2: Напрямую через Go
```bash
go run ./cmd/server
```

### Опция 3: Собрать бинарник
```bash
go build -o server ./cmd/server

## 🎯 Основные компоненты

### 1. **Models** 📦
Содержит структуры данных:
- `Message` - сообщение с временной меткой
- `Client` - подключенный клиент

### 2. **Database** 💾
Управляет SQLite:
- Сохранение сообщений
- Получение истории
- Подсчет сообщений
- Очистка старых данных

### 3. **Hub** 🔄
Центральный диспетчер:
- Управляет клиентами
- Трансляция сообщений
- Статистика сервера

### 4. **Server** 🌐
HTTP сервер и обработчики:
- REST API эндпоинты
- WebSocket upgrade
- Обработка сообщений
